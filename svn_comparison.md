# Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
Ветвление: В Git ветка — это легкий указатель на коммит (41 байт), который создается мгновенно. В SVN ветка — это копия всей директории на сервере, требующая ресурсов и сложного слияния.
# Можно ли в SVN сделать коммит без интернета? Почему?
Коммит без интернета в SVN: Нельзя. SVN — централизованная система. История хранится только на сервере, и коммит требует присвоения глобального номера ревизии сервером.
Когда SVN лучше Git:
- Бинарные файлы: Удобнее работать с тяжелыми гигабайтными ассетами (3D, видео, графиками).
- Частичный чекаут: Можно выкачать только одну нужную папку, а не весь репозиторий.
- Гибкие права: Можно дать доступ только к отдельной подпапке проекта.
- Блокировка файлов (lock): Защищает несливаемые файлы (например, .psd) от одновременного редактирования.
